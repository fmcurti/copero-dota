# Audio sources

The Pudge modal uses these Dota 2 Meat Hook game samples:

- `pudge-hook-throw.mp3` — `Weapons hero pudge hook throw`
- `pudge-hook-impact.mp3` — `Weapons hero pudge hook impact`
- `pudge-hook-retract-stop.mp3` — `Weapons hero pudge hook retract stop`

They were retrieved from the corresponding media pages in the
[Dota 2 Wiki Pudge sound category](https://dota2.fandom.com/wiki/Category:Sounds_weapons_hero_pudge).
